# 📚 Next.js Course Project

This repository contains my solutions and assignments for a Next.js course.  
The project covers the fundamentals of modern React and Next.js development, including routing, styling, API routes, rendering strategies, testing, deployment, and optimization.

[Demo](https://next-js-tasks-kappa.vercel.app/)

---

# 🚀 Features

## ⚛️ React & Next.js Basics

- React component structure
- Routing with App Router
- Navigation between pages
- Dynamic routes
- Layouts and reusable components

## 🎨 Styling

- CSS Modules
- Global CSS
- Tailwind CSS integration
- Styled UI components
- Responsive layouts

## 🔌 API Routes

- GET and POST API routes
- Dynamic API endpoints
- Form validation
- Authentication checks
- JSON responses with NextResponse

## 🌐 SSR, SSG & ISR

- Server Side Rendering (SSR)
- Static Site Generation (SSG)
- Incremental Static Regeneration (ISR)
- Hybrid rendering strategies
- Dynamic data fetching with caching

## 🧠 State Management

- React Context API
- Shared state between components
- Avoiding prop drilling

## 🧪 Testing

- Jest setup with next/jest
- React Testing Library
- Unit testing components
- API route testing
- Mocking external APIs
- Playwright end-to-end testing

## 🚀 Deployment & Optimization

- Deployment to Vercel
- Image optimization with next/image
- Script optimization with next/script
- Production builds
- Performance improvements
